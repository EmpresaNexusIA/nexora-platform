# docs/services/

Un documento por servicio operativo (`postgres.md`, `n8n.md`,
`evolution-api.md`, ...), agregado por el sub-proyecto que construye ese
servicio. Explica qué hace, cómo se configura y cómo depurarlo — no es un
README genérico de Docker, es la referencia operativa del servicio.

Vacía a propósito en el sub-proyecto 1 (todavía no hay servicios de negocio).
